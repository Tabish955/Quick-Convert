Salam bhai, Phase 1 ka core kaam wrap up ho gaya hai aur repo pe push kar diya hai maine.

Tu ab `main` pull kar le aur apni nayi branch bana le:
git checkout main
git pull origin main
git checkout -b phase-2-ui

Tera main kaam UI ka visual redesign hai using Wpf.Ui controls (Fluent styling, Windows 11 rounded cards, acrylic/mica background, dark/light theme wagera). Maine saara MVVM wiring aur dependency injection pehle se set kar diya hai, so tujhe zero backend ya logic likhni paregi.

Tujhe bas yeh do files design karni hain inside `src/QuickConvert.UI/Views`:
1. `QuickPopupWindow.xaml`:
Yeh wo chota popup hai jo right-click pe cursor ke paas khulta hai. Isme ViewModel already hooked hai (`QuickPopupViewModel`). Tujhe direct properties mil jayengi:
- Header ke liye: `FileSummary`, `FileCount`, `DetectedCategory`
- Target format select karne ke liye: `AvailableTargetFormats` (ObservableCollection) aur `SelectedTargetFormat`
- Progress aur status: `OverallProgress` (0 to 100), `StatusMessage`, `IsConverting`, `ConversionCompleted`
- Buttons ke liye commands: `ConvertNowCommand`, `CancelConversionCommand`, `OpenFullDashboardCommand`, `OpenOutputFolderCommand`

2. `MainDashboardWindow.xaml`:
Yeh full batch converter window hai (`MainDashboardViewModel`). Iske andar:
- Queue list: DataGrid ya custom ListView bind kar de `Jobs` collection pe (har item me `FileName`, `FormattedFileSize`, `Category`, `TargetExtension`, `ProgressPercentage`, `StatusText` bindable hain).
- Top bar: `AddFilesCommand`, `SelectedGlobalFormat` & `AvailableGlobalFormats`, `OutputFolderPath`, `BrowseOutputFolderCommand`, `OpenOutputFolderCommand`.
- Actions: `StartQueueCommand`, `CancelAllCommand`, `ClearCompletedCommand`.

Best part yeh hai ke `MockConversionEngine` already chal raha hai. Tu `dotnet run --project src/QuickConvert.UI` karega ya VS me F5 dabayega, files drag drop karega aur Convert dabayega tou 2.5 seconds ka real-time animated progress bar aur dummy file create ho jayegi, so tu visually aaram se test kar sakta hai.

Bas ek do cheezon ka khayal rakhna:
- `QuickConvert.Core` ko touch mat karna, wo freeze hai.
- `.xaml.cs` code-behind me koi conversion ya business logic mat daalna, sab kuch ViewModel commands ke through bind karna.
- Root pe maine detailed `PHASE_2_SPEC.md` bhi daal diya hai agar properties ki exact types dekhni hon.

Check kar le aur koi issue ho tou bata.
